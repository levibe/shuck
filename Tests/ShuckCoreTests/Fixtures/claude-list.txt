Changes since the last release:
- Config loader: "include" → "extends" now resolves
  relative to the file that names it ("./base.toml",
  "../shared/…"). Before this it resolved against the
  working directory.
- Cache: stale entries are dropped when the lockfile
  changes, and a single "Cache cleared because
  dependencies changed" warning is printed. It only
  appears on the first run after the change, so CI logs
  stay quiet.
- Output: --format now accepts json, yaml, table, markdown
  / {a template path}, and each format has its own
  snapshot test. Table is still the default.
